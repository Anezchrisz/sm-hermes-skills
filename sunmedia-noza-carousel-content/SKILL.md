# Struktur Carousel

Satu paket konten Noza mencakup satu carousel (bisa lebih dari satu set bila `Task_Brief` memintanya eksplisit — default satu set per siklus `NORMAL`).

## 1. Jumlah slide

- Disarankan 6–10 slide untuk sebagian besar kasus (cukup untuk membangun satu ide, tidak terlalu panjang sampai orang swipe keluar sebelum sampai CTA).
- Slide pertama = hook (sama prinsipnya dengan hook video: 2–3 alternatif, pilih satu, catat alasan).
- Slide terakhir = CTA (bagian 3).
- Slide di antaranya = build-up: satu ide/poin per slide, jangan menumpuk beberapa poin di satu slide.

## 2. Field wajib per slide

1. **Nomor slide**
2. **Copy** (teks yang tampil di slide — singkat, satu ide utama)
3. **Arahan visual** (foto/ilustrasi/grafik apa, bukan hanya "gambar menarik" — sebutkan elemen konkret)
4. **Catatan status aset** (sama pola dengan video: `ASSET_READY` / `NEEDS_NEW_SHOOT` / `NEEDS_ASSET_CONFIRMATION`, berlaku per slide yang butuh foto/footage spesifik)

## 3. Slide CTA (terakhir)

- Satu tindakan jelas, sesuai `primary_offer` — konsisten dengan CTA di naskah video dan landing page Weba (message-match).
- Boleh menyertakan elemen urgensi/penawaran HANYA bila itu berasal dari `primary_offer`/Task_Brief, bukan dikarang Noza sendiri (lihat batas peran: dilarang mengarang KPI/penawaran).

## 4. Segmen bahasa

Sama seperti naskah video (lihat `sunmedia-noza-video-script-brief` bagian 3) — buat set carousel terpisah per segmen bila `language_matrix` menyebut lebih dari satu segmen, jangan dicampur dalam satu set.

## 5. Checklist

- [ ] 6–10 slide (atau jumlah lain dengan alasan eksplisit bila menyimpang)
- [ ] Slide pertama = hook dengan ≥2 alternatif tercatat
- [ ] Setiap slide tengah = satu ide, bukan tumpukan poin
- [ ] Slide terakhir = CTA tunggal, sesuai `primary_offer`
- [ ] Status aset dicatat per slide yang butuh foto/footage
